# jsonrpc11base

This is a simple JSON-RPC 1.1 library without and agnostic to a transport layer.

This repository includes a vendored copy of [jsonrpc11base](https://github.com/kbaseincubator/kbase-jsonrpc11base) to resolve dependency conflicts. The original repository was only used by this project, so the code has been brought in directly to simplify maintenance and eliminate external dependency issues.
